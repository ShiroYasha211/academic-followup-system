# دليل استخدام نظام المتابعة الأكاديمية

## الدخول إلى النظام

1. يفتح المستخدم التطبيق المناسب لدوره.
2. يدخل البريد الإلكتروني وكلمة المرور.
3. يتحقق النظام من بيانات الدخول والصلاحيات.
4. ينتقل المستخدم إلى لوحة التحكم المناسبة لدوره.

## دليل الطالب

### متابعة الصفحة الرئيسية

بعد تسجيل الدخول تظهر الصفحة الرئيسية، ومنها يستطيع الطالب الوصول إلى أهم الخدمات مثل المواد، الجدول، التنبيهات، الكويزات، والتكليفات.

### عرض المقررات

1. يفتح الطالب قائمة التطبيق.
2. يختار "المقررات الدراسية".
3. تظهر قائمة المواد المسجلة.
4. يمكنه فتح مادة محددة لمتابعة تفاصيلها والحضور المرتبط بها.

### متابعة الجدول الدراسي

1. يختار الطالب "الجدول الدراسي".
2. تظهر المحاضرات مرتبة حسب الأيام والمواعيد.
3. يستطيع الطالب معرفة المحاضرة القادمة وبياناتها.

### متابعة جداول الاختبارات

1. يختار الطالب "جداول الاختبارات".
2. تظهر الاختبارات حسب المواد والمواعيد.
3. يعتمد الطالب على هذه الصفحة لمتابعة الاختبارات القادمة.

### تسليم التكليفات

1. يختار الطالب "التكليفات والواجبات".
2. يفتح التكليف المطلوب.
3. يراجع الوصف والموعد النهائي.
4. يرفق ملف التسليم إذا كان مطلوباً.
5. يرسل التكليف وينتظر تحديث الحالة أو الدرجة.

### أداء الكويز

1. يختار الطالب "الكويزات".
2. يفتح الكويز المتاح.
3. يراجع صفحة الاستعداد قبل البدء.
4. يبدأ الاختبار ويجيب على الأسئلة.
5. يرسل الإجابات.
6. تظهر النتيجة حسب إعدادات الدكتور.

### إرسال استفسار للدكتور

1. يختار الطالب "استفسارات الدكتور".
2. ينشئ استفساراً جديداً.
3. يحدد المادة أو الموضوع.
4. يكتب السؤال.
5. يرسل الاستفسار ويتابع الرد من نفس الصفحة.

### متابعة التنبيهات

1. يختار الطالب "التنبيهات".
2. تظهر التنبيهات الواردة.
3. يمكن فتح التنبيه لمعرفة التفاصيل أو الانتقال للصفحة المرتبطة به.

## دليل المندوب

### إدارة بيانات الدفعة

1. يدخل المندوب إلى لوحة المندوب.
2. يفتح "الطلاب" لمتابعة بيانات طلاب الدفعة.
3. يفتح "المواد" لمتابعة المواد المرتبطة بالدفعة.
4. يستخدم "الجدول الدراسي" و"جداول الاختبارات" لتنظيم المواعيد.

### نشر إعلان للدفعة

1. يختار "إعلانات الدفعة".
2. يضيف إعلاناً جديداً.
3. يكتب العنوان والمحتوى.
4. يحفظ الإعلان ليظهر للطلاب المستهدفين.

### إدارة الحضور

1. يختار "رصد الحضور".
2. يحدد المادة أو المحاضرة حسب المتاح.
3. يسجل حضور الطلاب.
4. يراجع السجل قبل الحفظ النهائي.

### بدء جلسة QR

1. يفتح بطاقة جلسة QR من لوحة المندوب أو من قسم الحضور.
2. يبدأ جلسة جديدة.
3. يتابع الطلاب الذين تم مسحهم.
4. ينهي الجلسة بعد اكتمال التسجيل.

### متابعة إنذارات الغياب

1. يختار "إنذارات الغياب".
2. يراجع الطلاب الذين لديهم حالات تحتاج متابعة.
3. يستخدم البيانات للتواصل أو التنبيه الأكاديمي.

## دليل الدكتور

### متابعة لوحة التحكم

بعد الدخول تظهر لوحة الدكتور وفيها ملخص سريع للمواد، الطلاب، الأنشطة، التنبيهات، والاختصارات.

### إدارة الحضور

1. يختار الدكتور "الحضور".
2. يحدد المادة أو المحاضرة.
3. يراجع حالة حضور الطلاب.
4. يحدث السجلات حسب الصلاحيات.

### مراجعة أعذار الغياب

1. يختار "أعذار الغياب".
2. يفتح العذر المطلوب.
3. يراجع بيانات الطالب والمادة والسبب.
4. يقبل أو يرفض العذر حسب السياسة المعتمدة.

### إنشاء تكليف

1. يختار "التكاليف".
2. يضغط إضافة.
3. يكتب عنوان التكليف ووصفه.
4. يربطه بالمادة.
5. يحدد تاريخ التسليم.
6. يحفظ التكليف ليظهر للطلاب.

### إدارة الدرجات

1. يختار "الدرجات".
2. يحدد المادة أو الطالب حسب الواجهة المتاحة.
3. يراجع الدرجات أو يحدثها حسب الصلاحيات.

### إنشاء إعلان

1. يختار "إعلاناتي".
2. يضغط إضافة إعلان.
3. يكتب العنوان والمحتوى.
4. يحدد نوع الإعلان أو المادة المرتبطة.
5. يحفظ الإعلان.

### إدارة الكويزات

1. يختار "الكويزات".
2. ينشئ كويزاً جديداً أو يفتح كويزاً موجوداً.
3. يحدد إعدادات الاختبار.
4. يضيف الأسئلة.
5. يتابع النتائج بعد أداء الطلاب للاختبار.

### الرد على استفسارات الطلاب

1. يختار "استفسارات الطلاب".
2. يفتح الاستفسار.
3. يقرأ السؤال.
4. يكتب الرد ويحفظه.

## دليل المسؤول الإداري

### إدارة الطلاب

1. يختار "الطلاب".
2. يستعرض قائمة الطلاب.
3. يضيف طالباً جديداً أو يعدل بيانات طالب حسب الصلاحيات.

### إدارة الدكاترة

1. يختار "الدكاترة".
2. يستعرض الحسابات.
3. يضيف أو يعدل بيانات الدكتور.
4. يحدد الصلاحيات المرتبطة بالحساب عند الحاجة.

### إدارة المندوبين

1. يختار "المندوبون".
2. يتابع حسابات المندوبين.
3. يضبط الصلاحيات حسب حاجة الدفعة.

### إدارة المواد والتخصصات

1. يفتح "التخصصات" لإدارة التخصصات والمستويات.
2. يفتح "المواد" لإضافة أو تعديل المواد وربطها بالدكاترة.

### إدارة الجداول

1. يفتح "الجداول الدراسية" لإدارة المحاضرات.
2. يفتح "جداول الاختبارات" لإدارة الاختبارات.
3. يحدد التخصص، المستوى، المادة، اليوم، الوقت، والبيانات المرتبطة.

### إرسال إشعار جماعي

1. يختار "إشعارات الكلية".
2. يضغط إضافة إشعار.
3. يكتب العنوان ونص الرسالة.
4. يحدد الفئة المستهدفة.
5. يرسل الإشعار.

### متابعة التقارير

1. يفتح "التقارير".
2. يختار نوع التقرير المطلوب.
3. يراجع البيانات والإحصاءات المتاحة.
