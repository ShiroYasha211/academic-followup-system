# توثيق نظام المتابعة الأكاديمية

هذا المجلد يحتوي على توثيق مشروع **نظام المتابعة الأكاديمية** بصيغة Markdown، وموجه حالياً للاستخدام في مشروع التخرج.

## الملفات

- [01-overview.md](01-overview.md): نظرة عامة على فكرة النظام، المشكلة، الأهداف، والقيمة.
- [02-features.md](02-features.md): شرح تفصيلي للميزات حسب كل دور داخل النظام.
- [03-user-guide.md](03-user-guide.md): دليل استخدام مختصر للطالب، المندوب، الدكتور، والمسؤول الإداري.
- [04-technical-documentation.md](04-technical-documentation.md): التوثيق التقني العام للبنية، التطبيقات، الربط، والصلاحيات.
- [05-presentation-script.md](05-presentation-script.md): سيناريو عرض مناسب لمناقشة مشروع التخرج.

## نطاق التوثيق

يركز هذا التوثيق على النظام باسم **نظام المتابعة الأكاديمية**، ويشرح الوظائف الأساسية المعتمدة للمستخدمين:

- تطبيق الطالب.
- تطبيق الكادر الأكاديمي.
- أدوار الطالب، المندوب، الدكتور، والمسؤول الإداري.
- لوحة الإدارة الخلفية بوصفها جزءاً داعماً لإدارة البيانات والصلاحيات.
